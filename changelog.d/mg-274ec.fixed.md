- **pm-template release-cut body: an enth repo now gets its own lane.** The release-cut hook knew only pogo's git flow (carve `release/vX.Y.Z`, `--post-merge-tag`, back-port to main). An enth repo mirrors to GitHub, so `gh release view` succeeded there and the hook filed that git-flow body for every enth cut. The hook now reads each repo's kind from `pogo project list --json` (`"vcs": "enth"`, matched on the resolved path, since basenames repeat across projects). For a vcs=enth repo it files a body that points at the repo's own `docs/release.md` lane: `enth tag vX.Y.Z <CHANGE>` on the deployed revision that passed the long suite, after which the push mirror creates the GitHub tag. Once the tag mirror is deployed, never `git push` a tag; until then, hand-push as before. A failed lookup skips the repo until the next sweep instead of falling back to the git body. The git body is byte-identical: the template line is unchanged, and the rendered body has the same sha1 on main and on this branch. (mg-274ec)
