- The `[stranded-push]` alert no longer fires on a polecat whose work is an open pull request awaiting review (drellem2/pogo#147). The release gate and the startup sweep now ask GitHub (`gh pr view`, through the refinery's PR lookup, moved to `internal/ghpr`) whether an open PR owns the branch's head; if one does, the finding is `awaiting_review`: no mail, but a `work_item_push_awaiting_review` event and a log line, and a sweep count. If the check fails (no `gh`, no auth, no network), the alert goes out as before, with the failure noted on the event and in the mail. Separately, `pushed` now means the head is on origin under any ref, not only under its own branch name. Work that was pushed under another branch's name no longer gets the LOCAL-ONLY "git-gc reaps it" warning or a `git push origin <branch> &&` remedy, and the remedy submits the branch name origin actually has (mg-dbb75).
