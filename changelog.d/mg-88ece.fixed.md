- **A 2+ Change enth stack self-lands again (mg-88ece).** `pogo presubmit --print-stack` prints the stack's ids on ONE line, space-separated, but the polecat templates' `self_land` read them one id per line, so a 2-Change stack reached `enth-land-gate` as the single argument `"id1 id2"` and was refused as "not a Change id"; nothing landed. The templates now split the line on any whitespace, in a form that works under both zsh and bash. The producer's format is kept, because a re-make writes the same line whole into its `Pogo-Supersedes` trailer, whose value must stay on one line (and `vcs.DropSuperseded` already splits it with `strings.Fields`). The format is now pinned as `enthvcs.PrintStackLine` and documented in `pogo presubmit --help`, and the self_land test feeds the producer's real output instead of a newline-joined stub. Polecats already running carry the old template; the fix reaches only those spawned after the template is live on the box.
