- **Host-local extra refinery gates per repo (mg-fb7df).** `[refinery.repos."<repo>"] extra_gates = ["<command>", ...]` in host config names quality gates that run after a repo's in-tree gates, in the same worktree, keyed by repo directory name or absolute path. They get `POGO_GATE_BASE`, `POGO_GATE_HEAD` and `POGO_GATE_TARGET`, so a gate can scan the diff and commit messages a merge would add. It is for checks that cannot live in the gated repo itself. pogod re-reads the section on every merge. With no such section, gating is unchanged. See docs/CONFIGURATION.md.
