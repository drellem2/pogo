- **The merge record names an enth landing (mg-01821, enth-vcs slice 8).** `mr.Landed()` returns what an MR landed as, by VCS: `(git, merged_sha)` or `(enth, <the land's new tip>)`. Every consumer that named a merge by its sha now names an enth merge as `enth <id>`. That covers the pogod `MERGED:` mail, the filer completion notice, the merged-but-open alert, the reopen guard, the merged-work dispatch refusal, the reap sidecar (`landed: {vcs, id}`), and `pogo refinery show`. `refinery_merged` carries `landed: {vcs, id}` for both kinds. The deploy hook gets `POGO_LANDED_VCS` and `POGO_LANDED_ID`. `merged_sha` stays absent on an enth MR, so tools that tag `.merged_sha` refuse rather than tag a Change id. A git MR's JSON, sidecar, mail and notices are byte-unchanged.
