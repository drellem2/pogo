- **`[agents] env`, `[agents.crew] env` and `[agents.polecat] env` set environment variables on spawned agents.** Each is a one-line array of `KEY=VALUE` entries; commas inside quoted elements are kept. `${POGO_AGENT_NAME}` in a value becomes the agent's name, so one line can give every crew agent its own value. Configured variables sit beneath pogo's identity variables and the spawn's own `--env`, so config cannot rename an agent or change its role. They apply to every spawn, crew boot and wake start, and restart. pogod warns at startup about each entry it cannot use, and `pogo agent env` lists the configured variables. See CONFIGURATION.md, "Agent environment".
