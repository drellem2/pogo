- **Messages about an enth MR no longer say `branch ` with nothing after it (mg-4377f, enth-vcs slice 8b).** An enth MR has no git branch, so every operator-facing message that formatted `branch %s` printed an empty branch. They now name the work item: `enth item <id>` in a sentence, `(none: enth item <id>)` under a `Branch:` label, and `item=<id>` in a `key=value` log line. This covers the merged-work dispatch refusal, the reopen guard's mail line, the merged-but-open alert and its log line, reap's MERGED BUT NOT CLOSED log line, the pogod `MERGED:` mail, `pogo refinery show`, the busy-repo reason, progress-watch notes, the unrouted fail-mail reason, and the refinery's merged, cancelled and post-merge log lines. Git output is byte-unchanged.
