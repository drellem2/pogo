- **`POST /agents/{name}/resize` sets an agent's PTY size over HTTP (drellem2/pogo#298, mg-834cf).** Send a JSON `{"cols","rows"}` body and pogod applies it with the same `applyResize` that local attach and the WebSocket terminal use. A remote attach plane can now size an agent's terminal, so its raw-socket attach no longer stairsteps. Unknown, not-running or PTY-less agents answer 404, which callers treat as a no-op. A missing, zero, negative or over-65535 dimension answers 400 rather than a silent no-op. A repeat of the current size sends no SIGWINCH. Based on a patch from the payitgov plane.
