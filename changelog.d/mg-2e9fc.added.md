- **An enth repo stops at the GitHub boundary (mg-2e9fc, enth-vcs slice 9).** An enth repo has no pull requests: its GitHub repo is an export mirror that only enth writes. So a PR-flow polecat on an enth repo is refused at spawn with a 409. That covers the `polecat-build-pr` template and a `--branch` or item `branch:` that is not the repo's trunk. The stranded-work check no longer asks GitHub for an open PR there. It asks whether the refinery holds an MR for the item, records any match as `open_mr`, and a refinery it cannot read still sends the alert. The closing-ref check for enth Changes reads each whole message, subject included, and never a PR body. The enth land pipeline (slice 7) will call it. `pogo doctor --check` gets an `enth in PATH` row, shown only when some project is an enth repo: missing is a fail, and an enth older than #9 is a warn. Nothing changes for git repos.
