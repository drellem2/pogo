- **A restarted agent keeps the environment it was spawned with.** pogod's restart path rebuilt an agent's environment from the identity catalogue alone, so an agent restarted after a crash lost every `--env` it was spawned with, and a restarted polecat lost its core budget (`POGO_WORKER_CORES`, `POGO_HOST_CORES`) and `POGO_ROLE`. The spawn's env is now kept on the agent (unexported, so the agents API never serializes it) and re-applied on every restart, in the same order as at spawn. Both spawn and restart now build the environment through one function, `processEnv`.
